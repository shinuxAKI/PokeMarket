# PokéMarket
.NET 10 solution with two independent ASP.NET Core MVC apps. PokemonMvc owns its catalogue database and publishes JSON. PokeMarketApi fetches catalogue data over HTTP and stores its own portfolio/listings/accounts in a separate SQLite database. Open PokeMarket.sln in Visual Studio 2026. Start PokemonMvc first (default https://localhost:7165), then PokeMarketApi (https://localhost:7265). Update CatalogApi:BaseUrl if the MVC port differs. This is a school demo: no real payment processing, shipping, escrow, PSA verification or settlement. Historical charts remain unavailable until a licensed price-history provider is configured; no fake history is generated.
